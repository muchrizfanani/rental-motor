# Program Rental Motor

Program ini merupakan aplikasi sederhana untuk menghitung total biaya sewa motor menggunakan konsep Object-Oriented Programming (OOP) dalam bahasa Java.

## Fitur
- Menghitung total biaya sewa motor berdasarkan lama sewa dan harga per hari.
- Memberikan diskon 10% apabila lama sewa lebih dari 5 hari.
- Menampilkan invoice secara otomatis di layar.
